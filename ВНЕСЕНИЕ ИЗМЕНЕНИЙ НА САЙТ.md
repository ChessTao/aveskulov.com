# Внесение изменений на сайт

## Короткий порядок

1. Внести правки в исходники, обычно в папке `src`.
2. Если правится главная страница, помнить: корневой `index.html` генерируется из `src/index.template.html` и файлов `src/sections/*.html`.
3. Запустить сборку:

```powershell
npm.cmd run build
```

4. Проверить локально изменённые страницы и важные файлы.
5. Проверить git:

```powershell
git status --short
```

6. Закоммитить изменения и запушить:

```powershell
git add <нужные файлы>
git commit -m "Короткое описание изменения"
git push
```

7. Попросить Codex создать новую версию OpenAI Hosting, используя `.openai/hosting.json`.
8. После сохранения версии попросить Codex задеплоить её в production.
9. После деплоя проверить production URL:

```text
https://aveskulov-chess-coaching.vdaveskulov.chatgpt.site
```

10. Для `best-games` отдельно проверить, что открывается страница, загружаются Stockfish JS/WASM и запускается движок.

## Важные файлы

- `src/sections/students.html` — карточки учеников.
- `src/index.template.html` — шаблон главной страницы.
- `build-static.mjs` — сборка статического сайта и упаковка для OpenAI Hosting.
- `.openai/hosting.json` — связь локального проекта с OpenAI Hosting.
- `openai-hosting-deploy-algorithm.md` — полный алгоритм публикации и проверки.

## Не забыть

- Не деплоить незакоммиченные изменения.
- Не добавлять в git локальные архивы и служебные файлы.
- После правок на странице студентов запускать `npm.cmd run build`, потому что production использует собранный `index.html`.
